# Tests

This folder holds the evaluation results for the controlled matching scenarios defined in `prototype/scenarios/`, per lecturer condition R5. It is not usability testing with real participants, since R5 currently rules out a real pilot; see `design-record/006-controlled-prototype-evaluation.md`.

- `matching-scenario-results.md`: one row per scenario: initial state, expected result, actual result, and whether the matching rule behaved correctly. "Actual result" is filled in once the matching/reassignment logic exists to run against.
